1. Three-layer architecture — source / graph service / generated catalogue

This is the skills system’s own internal architecture, as implemented in the shared submodules/skills library (internal/skillsource, internal/skill, internal/codegraph, internal/skillscatalog). Skill content flows from raw sources (filesystem or GitHub), through a parse-and-map pipeline into a persistent dependency graph enriched with CodeGraph-sourced evidence, and out to a deterministic, byte-stable generated Markdown catalogue with a drift-proof fingerprint sidecar.

Sources: submodules/skills/internal/skillsource/sync.go (Orchestrator, SyncSource, runPipeline, fetchSource, parseContent, mapSkills); submodules/skills/internal/skill/store.go (Store, AddDependency, GetDependents); submodules/skills/internal/codegraph/index.go (IndexManager, SymbolsToEvidence); submodules/skills/internal/skillscatalog/ (doc.go, generate.go, fingerprint.go — computeRosterFingerprint, writeFingerprintSidecar).
